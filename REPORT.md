## 2. Відповідь на контрольне запитання

**Запитання:** `Що таке множина в Python і які її основні властивості?`

**Відповідь:**

** Множина в Python - це вбудована структура даних для зберігання колекції унікальних елементів у невпорядкованому вигляді. Її основні властивості: унікальність (автоматичне видалення дублікатів), невпорядкованість (відсутність індексів та доступу за ними), можливість зміни самої множини (можна додавати або видаляти елементи, але самі елементи мають бути незмінними, наприклад, числа або рядки) та висока швидкість перевірки наявності елементів завдяки хешуванню. Множини надзвичайно зручні для математичних операцій, таких як об’єднання (|), перетин (&) та різниця (-), оскільки дозволяють швидко знаходити спільні або унікальні елементи між колекціями.
